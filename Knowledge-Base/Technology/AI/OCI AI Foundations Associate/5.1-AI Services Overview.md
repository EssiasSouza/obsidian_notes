# 5.1-AI Services Overview

In this lesson, I will take you through an overview of OCI AI services. Oracle has been focusing on bringing to the enterprise at every layer of our stack. It all begins with data and infrastructure layers. OCI AI services consume data, and AI services in turn are consumed by applications. This approach involves extensive investment from infrastructure to SaaS applications. Generative AI and massive scale models are the more recent steps. Oracle AI is the portfolio of cloud services for helping organizations use the data they may have for the business-specific uses.

Business applications consume AI and ML services. The foundation of AI services and ML services is data. AI services contain prebuilt models for specific uses. Some of the AI services are pretrained, and some can be additionally trained by the customer with their own data. AI services can be consumed by calling the API for the service, passing in the data to be processed, and the service returns a result. There is no infrastructure to be managed for using AI services. In this lesson, the focus is on OCI AI services.

OCI AI services provide multiple methods for access. The most common method is the OCI Console. The OCI Console provides an easy-to-use, browser-based interface that enables access to notebook sessions and all the features of all the data science, as well as AI services. Rest API, the Rest API provides access to service functionality but requires programming expertise. An API reference is provided in the product documentation.

Language SDK OCI also provides programming language SDK for Java, Python, TypeScript/JavaScript, Net, Go, and Ruby. The command line interface provides both quick access and full functionality without the need for scripting. Let us see what type of OCI services are available.

OCI AI services is a collection of services with prebuilt machine learning models that make it easier for developers to build a variety of business applications. The models can also be custom trained for more accurate business results. The different services provided are Digital Assistant, Language, Vision, Speech, Document Understanding. Let us explore each one of these services.

OCR Language allows you to perform sophisticated text analysis at scale. Using the pretrained and custom models, you can process unstructured text to extract insights without data science expertise. Language services are provided by pretrained models, custom models, and text translation. Pretrained models include language detection, sentiment analysis, key phrase extraction, text classification, named entity recognition, and personal identifiable information detection. Custom models can be trained for named entity recognition and text classification with domain-specific data sets.

In text translation, neural machine translation is used to translate text across numerous languages. Using OCR Vision, you can upload images to detect and classify objects in them. Pretrained models and custom models are supported. In Image Analysis, pretrained models perform object detection, image classification, and optical character recognition.

In image analysis, custom models can perform custom object detection by detecting the location of custom objects in an image and providing a bounding box. The custom image classification builds a model to identify objects and scene-based features in an image. The OCI Speech service is used to convert media files to readable texts that's stored in JSON and SRT format. Speech enables you to easily convert media files containing human speech into highly exact text transcriptions.

Using OCI Document Understanding you can upload documents to detect and classify text and objects in them. You can process individual files or batches of documents. And OCR Document Understanding can detect and recognize text in a document. In text extraction, Document Understanding provides the word level and line level text and the bounding box coordinates of where the text is found.

In Key Value Extraction, Document Understanding extracts a predefined list of key value pairs of information from receipts, invoices, passports, and driver IDs. In Table Extraction, Document Understanding extracts content and tabular format, maintaining the row and column relationship of cells. In Document Classification, the Document Understanding classifies documents into different types.

Oracle Digital Assistant is a platform that allows you to create and deploy digital assistants, which are AI-driven interfaces that help users accomplish a variety of tasks with natural language conversations. When a user engages with the Digital Assistant, the Digital Assistant evaluates the user input and routes the conversation to and from the appropriate skills. Digital Assistant greets the user upon access, upon user request, lists what it can do, and provide entry points into the given skills. It routes explicit user requests to the appropriate skills. And it also handles interruptions to flows and disambiguation. It also handles requests to exit the bot. Thanks for listening.

# 5.1 - **Descripción general de los servicios de IA**

En esta lección, les presentaré una descripción general de los servicios de IA de OCI. Oracle se ha enfocado en brindar soluciones empresariales en cada capa de su plataforma. Todo comienza con las capas de datos e infraestructura. Los servicios de IA de OCI consumen datos, y a su vez, las aplicaciones consumen servicios de IA. Este enfoque implica una inversión considerable, desde infraestructura hasta aplicaciones SaaS . La IA generativa y los modelos a gran escala son los pasos más recientes. Oracle AI es el portafolio de servicios en la nube que ayuda a las organizaciones a utilizar los datos que poseen para fines específicos de negocio.

Las aplicaciones empresariales consumen servicios de IA y aprendizaje automático (ML). La base de estos servicios son los datos. Los servicios de IA contienen modelos predefinidos para usos específicos. Algunos servicios de IA están preentrenados , mientras que otros pueden ser entrenados adicionalmente por el cliente con sus propios datos. Para consumir servicios de IA, basta con llamar a la API del servicio, proporcionar los datos que se van a procesar y el servicio devuelve un resultado. No es necesario gestionar ninguna infraestructura para utilizar los servicios de IA. En esta lección, nos centraremos en los servicios de IA de OCI.

Los servicios de IA de OCI ofrecen múltiples métodos de acceso. El más común es la consola de OCI. Esta consola proporciona una interfaz intuitiva basada en navegador que permite acceder a las sesiones de notebooks y a todas las funcionalidades de los servicios de ciencia de datos e IA. La API REST permite acceder a la funcionalidad del servicio, pero requiere conocimientos de programación. En la documentación del producto se incluye una referencia de la API.

OCI también ofrece SDK para lenguajes de programación como Java, Python, TypeScript /JavaScript, .NET, Go y Ruby. La interfaz de línea de comandos proporciona acceso rápido y funcionalidad completa sin necesidad de scripts. Veamos qué tipo de servicios de OCI están disponibles.

Los servicios de IA de OCI son una colección de servicios con modelos de aprendizaje automático predefinidos que facilitan a los desarrolladores la creación de diversas aplicaciones empresariales. Los modelos también se pueden entrenar a medida para obtener resultados empresariales más precisos. Los diferentes servicios que se ofrecen son Asistente Digital, Lenguaje, Visión, Voz y Comprensión de Documentos . Exploremos cada uno de estos servicios.

OCR Language permite realizar análisis de texto sofisticados a gran escala. Mediante modelos preentrenados y personalizados, puede procesar texto no estructurado para extraer información valiosa sin necesidad de conocimientos de ciencia de datos. Los servicios lingüísticos se ofrecen mediante modelos preentrenados , modelos personalizados y traducción de texto. Los modelos preentrenados incluyen detección de idioma, análisis de sentimiento, extracción de frases clave, clasificación de texto, reconocimiento de entidades nombradas y detección de información personal identificable. Los modelos personalizados se pueden entrenar para el reconocimiento de entidades nombradas y la clasificación de texto con conjuntos de datos específicos del dominio.

En la traducción de texto, se utiliza la traducción automática neuronal para traducir textos a numerosos idiomas. Con OCR Vision, puede cargar imágenes para detectar y clasificar objetos en ellas. Se admiten modelos preentrenados y personalizados. En el análisis de imágenes, los modelos preentrenados realizan detección de objetos, clasificación de imágenes y reconocimiento óptico de caracteres.

En el análisis de imágenes, los modelos personalizados permiten la detección de objetos específicos, localizando dichos objetos en la imagen y definiendo su área delimitada. La clasificación de imágenes personalizada crea un modelo para identificar objetos y características de la escena. El servicio OCI Speech se utiliza para convertir archivos multimedia en textos legibles, almacenados en formato JSON y SRT. Speech facilita la conversión de archivos multimedia con voz humana en transcripciones de texto de alta precisión.

Con OCI Document Understanding, puede cargar documentos para detectar y clasificar texto y objetos. Puede procesar archivos individuales o lotes de documentos. Además, OCR Document Understanding detecta y reconoce texto en un documento. En la extracción de texto, Document Understanding proporciona el texto a nivel de palabra y línea, así como las coordenadas del cuadro delimitador donde se encuentra el texto.

En la extracción de pares clave-valor, el sistema de comprensión de documentos extrae una lista predefinida de pares clave-valor de recibos, facturas, pasaportes e identificaciones de conductores. En la extracción de tablas, el sistema de comprensión de documentos extrae el contenido y el formato tabular, manteniendo la relación de filas y columnas de las celdas. En la clasificación de documentos, el sistema de comprensión de documentos clasifica los documentos en diferentes tipos.

Oracle Digital Assistant es una plataforma que permite crear e implementar asistentes digitales, interfaces basadas en IA que ayudan a los usuarios a realizar diversas tareas mediante conversaciones en lenguaje natural. Cuando un usuario interactúa con el Asistente Digital, este evalúa la información que proporciona y dirige la conversación a las habilidades adecuadas. El Asistente Digital saluda al usuario al acceder, responde a sus solicitudes, enumera sus funciones y proporciona puntos de acceso a las habilidades disponibles. Dirige las solicitudes explícitas del usuario a las habilidades correspondientes. Además, gestiona las interrupciones en el flujo de trabajo y la desambiguación. También gestiona las solicitudes para salir del bot. Gracias por su atención.
