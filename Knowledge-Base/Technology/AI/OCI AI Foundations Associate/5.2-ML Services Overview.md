# 5.2-ML Services Overview

As we have already seen, Oracle is this portfolio of cloud services for helping organizations take advantage of all data for the next generation of scenarios. The foundations of AI services and ML services layer is data.

Obviously, AI and machine learning work on data and required it. The top layer of this diagram is applications and loosely refers to all the ways AI is consumed. This could be an application, a business process, or an analytics system. Between the application and data layer, you see two groups here-- the AI services on the top and the machine learning services on the bottom.

We have already seen about AI services in the lesson titled AI Services Overview. In this lesson, we are going to primarily focus on OCI Data Science as a part of machine learning services. So what is Oracle Cloud Infrastructure Data Science? OCI Data Science is the cloud service focused on serving the data scientists throughout the full machine learning life cycle, with support for Python and open source.

As you can see by icon in this graphic, the service has many features, such as model catalog, projects, JupyterLab Notebook, model deployment, model training, management, model explanation, open-source libraries, and AutoML. There are three core principles of OCI Data Science. The first one, accelerated. The first principle is about accelerating the work of the individual data scientist. OCI Data Science provides data scientists with open-source libraries, along with easy access to a range of compute power, without having to manage any infrastructure. It also includes Oracle's own library to help streamline many aspects of their work.

The second principle is collaborative. It goes beyond an individual data scientist's productivity to enable data science teams to work together. This is done through the sharing of assets, reducing duplicative work, and putting reproducibility and auditability of models for collaboration and risk management.

Third is enterprise grade. That means it's integrated with all the OCI security and access protocols. The underlying infrastructure is fully managed. The customer does not have to think about provisioning compute and storage. And the service handles all the maintenance, patching, and upgrades so user can focus on solving business problems with data science.

So having seen the core principles, let's drill down a bit more into the specifics of OCI Data Science. So again, what is OCI Data Science? It's a cloud service to rapidly build, train, deploy, and manage machine learning models. Whom does it serve? It serves data scientists and data science teams throughout the full machine learning life cycle, with support for Python and open source.

Where it is being used-- users work in a familiar JupyterLab Notebook interface, where they write Python code. And how it is used-- so users preserve their models in the model catalog and deploy their models to a managed infrastructure.

Some of the important product terminology of OCI Data Science are projects. The projects are containers that enables data science teams to organize their work. They represent collaborative workspaces for organizing and documenting data science assets such as notebook sessions and models.

Note that tenancy can have as many projects as needed without limits. Now this notebook session is where the data scientists work. Notebook sessions provide a JupyterLab environment with preinstalled open-source libraries and the ability to add others.

Notebook sessions are interactive coding environment for building and training models. Notebook sessions run in a managed infrastructure, and the user can select CPU or GPU, the compute shape, and amount of storage without having to do any manual provisioning.

The other important feature is Conda environment. It's an open-source environment and package management system and was created for Python programs. It is used in the service to quickly install, run, and update packages and their dependencies. Conda easily creates, saves, loads, and switches between environments in your notebook sessions.

The next one is Accelerated Data Science SDK. Oracle's Accelerated Data Science, ADS, SDK is a Python library that is included as part of OCI Data Science. ADS has many functions and objects that automate or simplify the steps in the Data Science workflow, including connecting to data, exploring and visualizing data, training a model with AutoML, evaluating models, and explaining models. In addition, ADS provides a simple interface to access the Data Science service, Model Catalog, and other OCI services, including Object Storage.

The next one is models. You already know what a model is. Models define a mathematical representation of your data and business process. You create models in notebooks, sessions, and side projects.

The next terminology is Model Catalog. The Model Catalog is a place to store, track, share, and manage models. The Model Catalog is a centralized and managed repository of model artifacts.

A stored model includes metadata about the provenance of the model, including Git-related information, and the script-- all notebook used to push the model to the catalog. Models stored in the Model Catalog can be shared across members of a team, and they can be loaded back into a notebook session.

The next one is model deployments. Model deployments allow you to deploy models stored in the Model Catalog as HTTP endpoints on managed infrastructure, deploying machine learning models as web applications, HTTP API endpoints. Serving predictions in real-time is the most common way to operationalize models. HTTP endpoints or the API endpoints are flexible and can serve requests for the model predictions. The last one which we are going to see here is jobs. Data Science jobs enable you to define and run a repeatable machine learning tasks on fully managed infrastructure.

# 5.2-Descripción general de los servicios de aprendizaje automático

Como ya hemos visto, Oracle ofrece una cartera de servicios en la nube para ayudar a las organizaciones a aprovechar al máximo sus datos en los escenarios de la próxima generación. La base de los servicios de IA y ML son los datos.

Obviamente, la IA y el aprendizaje automático funcionan con datos y los requieren. La capa superior de este diagrama representa las aplicaciones y se refiere, en términos generales, a todas las formas en que se utiliza la IA. Esto podría ser una aplicación, un proceso de negocio o un sistema de análisis. Entre la capa de aplicaciones y la de datos, se observan dos grupos: los servicios de IA en la parte superior y los servicios de aprendizaje automático en la inferior.

Ya hemos visto información sobre servicios de IA en la lección titulada "Descripción general de los servicios de IA". En esta lección, nos centraremos principalmente en OCI Data Science como parte de los servicios de aprendizaje automático. ¿Qué es Oracle Cloud Infrastructure Data Science? OCI Data Science es el servicio en la nube diseñado para brindar soporte a los científicos de datos durante todo el ciclo de vida del aprendizaje automático, con soporte para Python y software de código abierto.

Como puede ver en el icono de este gráfico, el servicio cuenta con numerosas funciones, como catálogo de modelos, proyectos, JupyterLab Notebook, implementación de modelos, entrenamiento de modelos, gestión, explicación de modelos, bibliotecas de código abierto y AutoML. OCI Data Science se basa en tres principios fundamentales. El primero es la aceleración. Este principio se centra en agilizar el trabajo del científico de datos. OCI Data Science proporciona a los científicos de datos bibliotecas de código abierto, junto con un acceso sencillo a una amplia gama de capacidad de procesamiento, sin necesidad de gestionar ninguna infraestructura. También incluye la propia biblioteca de Oracle para optimizar muchos aspectos de su trabajo.

El segundo principio es la colaboración. Va más allá de la productividad individual de un científico de datos para permitir que los equipos de ciencia de datos trabajen juntos. Esto se logra mediante el intercambio de recursos, la reducción del trabajo duplicado y la priorización de la reproducibilidad y la auditabilidad de los modelos para la colaboración y la gestión de riesgos.

En tercer lugar, tenemos la versión de nivel empresarial. Esto significa que está integrada con todos los protocolos de seguridad y acceso de OCI. La infraestructura subyacente está totalmente gestionada. El cliente no tiene que preocuparse por el aprovisionamiento de recursos informáticos y de almacenamiento. Además, el servicio se encarga de todo el mantenimiento, las actualizaciones y las correcciones, para que el usuario pueda centrarse en resolver problemas empresariales mediante la ciencia de datos.

Ahora que hemos visto los principios básicos, profundicemos un poco más en los detalles de OCI Data Science. ¿Qué es OCI Data Science? Es un servicio en la nube para crear, entrenar, implementar y administrar rápidamente modelos de aprendizaje automático. ¿A quién sirve? Sirve a científicos de datos y equipos de ciencia de datos durante todo el ciclo de vida del aprendizaje automático, con soporte para Python y software de código abierto.

Dónde se utiliza: los usuarios trabajan en una interfaz familiar de JupyterLab Notebook, donde escriben código Python. Y cómo se utiliza: los usuarios conservan sus modelos en el catálogo de modelos y los implementan en una infraestructura administrada.

Algunos de los términos clave de OCI Data Science son los proyectos. Estos proyectos son contenedores que permiten a los equipos de ciencia de datos organizar su trabajo. Representan espacios de trabajo colaborativos para organizar y documentar recursos de ciencia de datos, como sesiones de notebooks y modelos.

Tenga en cuenta que cada usuario puede tener tantos proyectos como necesite, sin límites. Esta sesión de Jupyter Notebook es donde trabajan los científicos de datos. Las sesiones de Jupyter Notebook proporcionan un entorno JupyterLab con bibliotecas de código abierto preinstaladas y la posibilidad de añadir otras.

Las sesiones de Notebook son entornos de codificación interactivos para crear y entrenar modelos. Estas sesiones se ejecutan en una infraestructura gestionada, y el usuario puede seleccionar la CPU o la GPU, la configuración de cómputo y la cantidad de almacenamiento sin necesidad de realizar ninguna configuración manual.

Otra característica importante es el entorno Conda. Se trata de un entorno de código abierto y un sistema de gestión de paquetes creado para programas Python. Se utiliza en el servicio para instalar, ejecutar y actualizar paquetes y sus dependencias rápidamente. Conda permite crear, guardar, cargar y cambiar entre entornos fácilmente en las sesiones de tu notebook.

El siguiente es el SDK de Ciencia de Datos Acelerada (ADS) de Oracle. El SDK de Ciencia de Datos Acelerada (ADS) es una biblioteca de Python incluida en OCI Data Science. ADS cuenta con numerosas funciones y objetos que automatizan o simplifican los pasos del flujo de trabajo de Ciencia de Datos, como la conexión a datos, la exploración y visualización de datos, el entrenamiento de modelos con AutoML, la evaluación de modelos y su explicación. Además, ADS proporciona una interfaz sencilla para acceder al servicio de Ciencia de Datos, al Catálogo de Modelos y a otros servicios de OCI, incluido el Almacenamiento de Objetos.

El siguiente tema son los modelos. Ya sabes qué es un modelo. Los modelos definen una representación matemática de tus datos y procesos de negocio. Puedes crear modelos en cuadernos, sesiones y proyectos paralelos.

El siguiente término es Catálogo de Modelos. El Catálogo de Modelos es un lugar para almacenar, rastrear, compartir y administrar modelos. Se trata de un repositorio centralizado y administrado de artefactos de modelos.

Un modelo almacenado incluye metadatos sobre su procedencia, incluyendo información relacionada con Git, y el script (todo el cuaderno utilizado para subir el modelo al catálogo). Los modelos almacenados en el Catálogo de Modelos se pueden compartir entre los miembros de un equipo y se pueden volver a cargar en una sesión de cuaderno.

El siguiente es el despliegue de modelos. El despliegue de modelos permite desplegar modelos almacenados en el Catálogo de modelos como puntos finales HTTP en infraestructura administrada, desplegando modelos de aprendizaje automático como aplicaciones web o puntos finales de API HTTP. Servir predicciones en tiempo real es la forma más común de operacionalizar los modelos. Los puntos finales HTTP o los puntos finales de API son flexibles y pueden atender solicitudes de predicciones del modelo. El último que veremos aquí son los trabajos. Los trabajos de ciencia de datos permiten definir y ejecutar tareas repetibles de aprendizaje automático en una infraestructura totalmente administrada.

# 5.2-Visão geral dos serviços de ML 

Como já vimos, a Oracle oferece um portfólio de serviços em nuvem que ajuda as organizações a aproveitar ao máximo seus dados para a próxima geração de cenários. A base dos serviços de IA e da camada de serviços de ML são os dados.

Obviamente, a IA e o aprendizado de máquina funcionam com dados e, portanto, precisam deles. A camada superior deste diagrama representa as aplicações e, de forma geral, engloba todas as maneiras pelas quais a IA é utilizada. Isso pode ser um aplicativo, um processo de negócios ou um sistema de análise. Entre a camada de aplicações e a camada de dados, podemos observar dois grupos: os serviços de IA na parte superior e os serviços de aprendizado de máquina na parte inferior.

Já vimos sobre serviços de IA na lição intitulada Visão Geral dos Serviços de IA. Nesta lição, vamos nos concentrar principalmente no OCI Data Science como parte dos serviços de aprendizado de máquina. Então, o que é o Oracle Cloud Infrastructure Data Science? O OCI Data Science é um serviço em nuvem focado em atender cientistas de dados durante todo o ciclo de vida do aprendizado de máquina, com suporte para Python e código aberto.

Como você pode ver pelo ícone neste gráfico, o serviço possui muitos recursos, como catálogo de modelos, projetos, JupyterLab Notebook, implantação de modelos, treinamento de modelos, gerenciamento, explicação de modelos, bibliotecas de código aberto e AutoML. Existem três princípios fundamentais do OCI Data Science. O primeiro deles é a aceleração. O princípio básico visa acelerar o trabalho do cientista de dados. O OCI Data Science fornece aos cientistas de dados bibliotecas de código aberto, juntamente com fácil acesso a uma ampla gama de recursos computacionais, sem a necessidade de gerenciar qualquer infraestrutura. Ele também inclui a biblioteca própria da Oracle para ajudar a otimizar diversos aspectos do trabalho.

O segundo princípio é a colaboração. Ele vai além da produtividade individual de um cientista de dados, permitindo que as equipes de ciência de dados trabalhem juntas. Isso é feito por meio do compartilhamento de recursos, da redução do trabalho duplicado e da promoção da reprodutibilidade e auditabilidade dos modelos para colaboração e gerenciamento de riscos.

A terceira opção é de nível empresarial. Isso significa que ela é integrada a todos os protocolos de segurança e acesso da OCI. A infraestrutura subjacente é totalmente gerenciada. O cliente não precisa se preocupar com o provisionamento de recursos de computação e armazenamento. E o serviço cuida de toda a manutenção, aplicação de patches e atualizações, para que o usuário possa se concentrar em resolver problemas de negócios com ciência de dados.

Agora que vimos os princípios básicos, vamos nos aprofundar um pouco mais nos detalhes do OCI Data Science. Então, o que é o OCI Data Science? É um serviço em nuvem para criar, treinar, implantar e gerenciar modelos de aprendizado de máquina rapidamente. Para quem ele serve? Ele atende cientistas de dados e equipes de ciência de dados em todo o ciclo de vida do aprendizado de máquina, com suporte para Python e código aberto.

Onde é utilizado: os usuários trabalham em uma interface familiar do JupyterLab Notebook, onde escrevem código Python. E como é utilizado: os usuários preservam seus modelos no catálogo de modelos e os implantam em uma infraestrutura gerenciada.

Alguns dos termos importantes do produto OCI Data Science são projetos. Os projetos são contêineres que permitem que as equipes de ciência de dados organizem seu trabalho. Eles representam espaços de trabalho colaborativos para organizar e documentar ativos de ciência de dados, como sessões de notebooks e modelos.

Note que cada sessão pode ter quantos projetos forem necessários, sem limites. É nesta sessão do JupyterLab que os cientistas de dados trabalham. As sessões do JupyterLab fornecem um ambiente JupyterLab com bibliotecas de código aberto pré-instaladas e a possibilidade de adicionar outras.

As sessões de notebook são ambientes de programação interativos para construir e treinar modelos. Elas são executadas em uma infraestrutura gerenciada, e o usuário pode selecionar CPU ou GPU, o formato de computação e a quantidade de armazenamento sem precisar realizar qualquer provisionamento manual.

Outro recurso importante é o ambiente Conda. Trata-se de um sistema de gerenciamento de pacotes e ambiente de código aberto, criado para programas em Python. Ele é utilizado no serviço para instalar, executar e atualizar pacotes e suas dependências rapidamente. O Conda facilita a criação, o salvamento, o carregamento e a alternância entre ambientes em suas sessões de notebook.

O próximo é o SDK de Ciência de Dados Acelerada (Accelerated Data Science SDK). O SDK de Ciência de Dados Acelerada da Oracle (ADS) é uma biblioteca Python incluída no OCI Data Science. O ADS possui diversas funções e objetos que automatizam ou simplificam as etapas do fluxo de trabalho de Ciência de Dados, incluindo a conexão com dados, a exploração e visualização de dados, o treinamento de um modelo com AutoML, a avaliação de modelos e a explicação de modelos. Além disso, o ADS fornece uma interface simples para acessar o serviço de Ciência de Dados, o Catálogo de Modelos e outros serviços do OCI, incluindo o Armazenamento de Objetos.

O próximo tópico são os modelos. Você já sabe o que é um modelo. Os modelos definem uma representação matemática dos seus dados e processos de negócio. Você cria modelos em notebooks, sessões e projetos paralelos.

O próximo termo é Catálogo de Modelos. O Catálogo de Modelos é um local para armazenar, rastrear, compartilhar e gerenciar modelos. O Catálogo de Modelos é um repositório centralizado e gerenciado de artefatos de modelos.

Um modelo armazenado inclui metadados sobre a proveniência do modelo, incluindo informações relacionadas ao Git, e o script — todo o notebook usado para enviar o modelo para o catálogo. Os modelos armazenados no Catálogo de Modelos podem ser compartilhados entre os membros de uma equipe e podem ser carregados novamente em uma sessão do notebook.

O próximo recurso são as implantações de modelos. As implantações de modelos permitem implantar modelos armazenados no Catálogo de Modelos como endpoints HTTP em infraestrutura gerenciada, implantando modelos de aprendizado de máquina como aplicativos web ou endpoints de API HTTP. Fornecer previsões em tempo real é a maneira mais comum de operacionalizar modelos. Os endpoints HTTP ou os endpoints de API são flexíveis e podem atender a solicitações de previsões do modelo. O último recurso que veremos aqui são os jobs. Os jobs de Ciência de Dados permitem definir e executar tarefas de aprendizado de máquina repetíveis em infraestrutura totalmente gerenciada.
